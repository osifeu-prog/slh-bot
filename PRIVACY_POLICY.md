# Privacy Policy - SLH OS

**Last updated: 2026-10-24**

SLH OS does not collect personal data beyond what is necessary for wallet connectivity and Telegram authentication.

- Telegram ID is used for authentication only
- Wallet addresses are stored for ownership verification
- No financial settlement is performed without explicit user consent and server-side gate verification
- Account deletion: Users can request deletion via /delete in Telegram bot

Contact: support@slh-nft.com
