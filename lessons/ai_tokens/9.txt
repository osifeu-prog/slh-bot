## איך מודדים טוקנים בפועל

אפשר להשתמש ב-tokenizer המתאים למודל כדי למדוד input/output ולבנות estimate.

העיקרון:
1. מדוד את ה-input האמיתי
2. הערך output צפוי
3. השתמש בתמחור העדכני של הספק
4. מדוד cache/context בנפרד
5. השווה בין גרסאות prompt

### אל תמדוד רק מחיר
מדדו גם:
- latency
- איכות תשובה
- שיעור שגיאות
- אורך context
- מספר פעולות המשך
- כמה פעמים המשתמש נאלץ לחזור על עצמו

### מדידה בסגנון ledger
לכל ניסוי שמרו:
Experiment ID
→ Prompt version
→ Model
→ Input tokens
→ Output tokens
→ Result
→ Evidence

כך אפשר להשוות ניסוי לניסוי במקום להסתמך על תחושה.

הגישה הזאת היא הבסיס ל-engineering שניתן לשחזר ולשפר.
